# Manga Tracker

เว็บแอปสำหรับติดตามการ์ตูนจาก manga-zaa.net ว่าเรื่องไหนมีตอนใหม่แล้ว โดยไม่ต้องไล่เปิดทีละลิงก์

- วางลิงก์ตอนไหนก็ได้ ระบบจะหาหน้ารวมของเรื่องให้เอง และจำว่าคุณอ่านถึงตอนนั้น
- GitHub Actions เช็คตอนใหม่ทุก 1 ชั่วโมง
- ป้าย "+N ตอนใหม่" บอกจำนวนตอนที่ยังไม่ได้อ่าน และปุ่ม "อ่านต่อ" จะเปิดตอนถัดไปที่ยังไม่ได้อ่านพร้อมบันทึกให้
- เปิดจากมือถือหรือคอมก็เห็นข้อมูลชุดเดียวกัน เพราะข้อมูลทั้งหมดเก็บอยู่ใน repo ของคุณ
- ใช้ฟรีทั้งหมด ใช้แค่ GitHub Pages และ GitHub Actions

## หลักการทำงาน

```
┌─────────────────────┐   ทุก 1 ชม. / เมื่อมีเรื่องใหม่   ┌──────────────┐
│ GitHub Actions      │ ─────────── อ่านหน้าเรื่อง ──────▶ │ manga-zaa    │
│ scripts/check.mjs   │                                  └──────────────┘
└─────────┬───────────┘
          │ commit data.json
          ▼
┌─────────────────────┐   อ่าน/เขียนผ่าน GitHub API   ┌──────────────────────┐
│ repo ของคุณ          │ ◀──────────────────────────▶ │ หน้าเว็บ (GitHub Pages) │
│ series.json         │   series.json, progress.json │ index.html           │
│ progress.json       │                              └──────────────────────┘
│ data.json           │
└─────────────────────┘
```

| ไฟล์ | ใครเขียน | เก็บอะไร |
|---|---|---|
| `series.json` | หน้าเว็บ | รายชื่อลิงก์ที่ติดตาม |
| `progress.json` | หน้าเว็บ | อ่านถึงตอนไหนแล้วของแต่ละเรื่อง |
| `data.json` | GitHub Actions | ชื่อเรื่อง ปก และรายการตอนล่าสุด |

แบ่งให้แต่ละไฟล์มีคนเขียนแค่ฝั่งเดียว ข้อมูลจะได้ไม่ชนกัน หน้าเว็บดึงข้อมูลจาก manga-zaa ตรงๆ ไม่ได้ เพราะเบราว์เซอร์บล็อก (CORS) งานดึงข้อมูลเลยให้ GitHub Actions ทำแทน

## ติดตั้ง (ประมาณ 10 นาที)

### 1. สร้าง repo แล้วอัปโหลดไฟล์

1. ไปที่ https://github.com/new ตั้งชื่อ เช่น `manga-tracker` แล้วเลือก **Public**
   (repo แบบ public ใช้ Actions ได้ไม่จำกัด ส่วนแบบ private มีโควตา 2,000 นาทีต่อเดือน ซึ่งก็ยังพอใช้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป หรือใช้คำสั่ง:

```bash
git init && git add . && git commit -m "Initial commit" && git branch -M main
```

```bash
git remote add origin https://github.com/<your-name>/manga-tracker.git && git push -u origin main
```

### 2. เปิด GitHub Pages

**Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main** / **(root)** แล้วกด Save

รอประมาณ 1 นาที เว็บจะอยู่ที่ `https://<your-name>.github.io/manga-tracker/`

### 3. อนุญาตให้ Actions เขียน repo

**Settings → Actions → General → Workflow permissions** → เลือก **Read and write permissions** แล้วกด Save

จากนั้นไปที่แท็บ **Actions** กดเปิดใช้งาน workflow (ถ้ามีปุ่มให้กด) แล้วกด **Check new chapters → Run workflow** เพื่อทดสอบหนึ่งรอบ

### 4. สร้าง token ให้หน้าเว็บบันทึกข้อมูลได้

1. ไปที่ https://github.com/settings/personal-access-tokens/new (Fine-grained token)
2. **Repository access:** Only select repositories → เลือก `manga-tracker`
3. **Permissions → Repository permissions → Contents:** Read and write
4. กด Generate แล้วคัดลอก token ไว้
5. เปิดหน้าเว็บ กดไอคอน ⚙ แล้ววาง token ลงไป (ถ้าเปิดผ่าน github.io ช่อง Owner/Repo จะกรอกให้เอง)

token จะถูกเก็บไว้ในเบราว์เซอร์เครื่องที่ใช้อยู่เท่านั้น แต่ละเครื่องต้องใส่ token ครั้งแรกเอง

## การใช้งาน

| อยากทำอะไร | ทำยังไง |
|---|---|
| เพิ่มเรื่อง | วางลิงก์ตอนที่อ่านล่าสุดแล้วกด **เพิ่มเรื่อง** ระบบจะตั้งว่าอ่านถึงตอนนั้นให้ และดึงข้อมูลภายใน 1–2 นาที |
| อ่านตอนถัดไป | กด **อ่านต่อ ตอน X** ระบบจะเปิดตอนนั้นในแท็บใหม่และบันทึกว่าอ่านแล้ว |
| อ่านทันแล้ว | กด ✓ บนการ์ด |
| แก้ตอนที่อ่านถึง / ลบเรื่อง | กดปุ่ม ⋯ มุมขวาบนของการ์ด |
| ใช้บนมือถือ | เปิดเว็บใน Safari หรือ Chrome แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" |

## ข้อควรรู้

- **เวลาที่ cron รัน:** GitHub อาจเริ่มรันช้ากว่าเวลาที่ตั้งไว้ 5–20 นาทีในช่วงที่คนใช้เยอะ
- **workflow อาจถูกปิดเอง:** ถ้า repo ไม่มีความเคลื่อนไหวเลย 60 วัน GitHub จะปิด workflow ตามรอบเวลาให้อัตโนมัติ แต่ปกติตอนที่กดอ่านหรือเจอตอนใหม่จะมี commit เกิดขึ้นอยู่แล้ว ถ้าถูกปิดก็เข้าไปเปิดใหม่ได้ในแท็บ Actions
- **ถ้าการ์ดขึ้น "ดึงข้อมูลไม่ได้":** อาจเป็นเพราะเว็บต้นทางล่ม เปลี่ยนโครงสร้างหน้า หรือ Cloudflare บล็อก IP ของ GitHub ดู log ได้ที่แท็บ Actions
- **ลองรันบนเครื่องตัวเอง:** ใช้คำสั่ง `node scripts/check.mjs` (ต้องใช้ Node 20 ขึ้นไป) แล้วเปิดหน้าเว็บด้วย `python3 -m http.server` ถ้าไม่ได้เชื่อม GitHub หน้าเว็บจะอ่านไฟล์ในโฟลเดอร์แบบอ่านอย่างเดียว

## เพิ่มเว็บอื่นในอนาคต

ฟังก์ชันที่อ่านหน้าเว็บอยู่ใน `scripts/check.mjs` คือ `findSeriesUrl()` กับ `parseSeries()` ถ้าจะรองรับเว็บอื่น ให้เพิ่มฟังก์ชันแบบเดียวกันแล้วเลือกใช้ตาม hostname จากนั้นเพิ่มโดเมนใน `ALLOWED_HOST` ใน `assets/app.js`
